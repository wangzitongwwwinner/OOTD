# M6-03 抠图任务 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立衣物抠图任务的创建、状态查询、失败重试和腾讯云 MPS 适配边界，并让小程序展示处理状态。

**Architecture:** 云函数以可信微信身份读取衣物草稿并创建用户隔离任务，领域层只依赖 `CutoutProvider`。MPS 适配器使用 `ProcessImage` 的固定 `ScheduleId=30031`，再以 `DescribeImageTaskDetail` 查询；未配置或未开通时返回友好可重试错误，不调用外部服务。

**Tech Stack:** TypeScript、Zod、CloudBase、Taro React、腾讯云 MPS Node.js SDK、Node test、Vitest。

## Global Constraints

- MPS 密钥只允许出现在云函数环境变量，不进入仓库、小程序或日志。
- 不自动开通 MPS、服务角色、COS 存储桶或自动后付费。
- 单次供应商请求超时 8 秒；后台最多重试 2 次。
- 抠图输出必须为 PNG，公开响应不得包含用户内部 ID、供应商密钥或原始异常。
- 客户端只轮询自己的任务；失败允许显式重试。
